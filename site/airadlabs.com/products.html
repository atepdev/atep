Products

AIRAD LABS plans services around the free, open protocol. These three offerings are planned. None is generally available, no certification has been issued, and there are no customers yet. What exists today is the open protocol, its reference implementations and a working demo.

ATEP Fleet Console (planned, not available)

Operators define a trust policy once and every robot verifies against it; revoke a compromised unit in one action; dashboards, alerts and an audit trail for incident review. The demo shows the behavior this console would drive (policy, revocation, named rejections) with simulated robots.

Certification (planned)

An audit by AIRAD LABS or a partner safety certifier, resulting in an attestation under a published root, with short lifetimes and renewal. No program is operating and no certifier partner has been announced.

Hosted registry and transparency log (planned)

A public log with inclusion proofs and monitoring for issuers. The log and monitor software already exists as open source in the reference implementation (plain HTTP, file storage); a hosted, operated service does not.

Available today, free and open

  • The specification (Draft 07) and 436 test vectors.
  • Reference implementations in Rust, JavaScript (WebAssembly) and Python, and carrier examples for MCP, A2A, MQTT and HTTP. No functional package is published to npm, crates.io or PyPI yet (placeholder names with no code are reserved at 0.0.1: crates.io atep, atep-core and atep-cli; npm @atep/core and @atep/mcp; PyPI atep).
  • The ATEP-R fleet demo, which runs in a browser from a local web server (see the demo README in the repository).

AIRAD LABS creates and stewards the open protocol ATEP (atep.dev). No customer, certification or hosted service is claimed on this site; everything under Products is planned unless it says otherwise.
