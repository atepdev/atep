Claims / registry-endpoint

Registry endpoint

https://atep.dev/claims/registry-endpoint core

Subject operates the service at the given URL (registry, verifier, MCP server or A2A agent).

Definition

Binds a service endpoint to an Agent ID through an ordinary attestation, so a client can find where an identity runs a registry, verifier, MCP server or A2A agent and check that the statement is logged. Attestations only: agent traffic is never logged (spec section 16 point 5).

kind is one of registry, verifier, mcp, a2a, or an extension name beginning with x-. A signed A2A agent card is carried by hashing the card JSON into the attestation evidence field and pointing evidence-uri at the card.

A log validates url (an https URL of at most 2048 characters with a host, no credentials and no whitespace) and kind at admission (schema_invalid); the core verifier does not check it. It is the seventh claim type of the core list of Draft 05, which with the seven robotics claim types makes 14.

The data layout

CDDL (RFC 8610) schema of the data map of an attestation with this claim:

registry-endpoint-data = { url: uri, kind: endpoint-kind, * tstr => any }
endpoint-kind = "registry" / "verifier" / "mcp" / "a2a" / (tstr .regexp "x-[a-z0-9-]+")
uri = tstr   ; an https URL

Example data in JSON form:

{
  "url": "https://registry.example.com/v1",
  "kind": "registry"
}

The whole attestation payload around data:

attestation = {
  subject: agent-id,
  issuer: agent-id,                      ; MUST equal the envelope signer
  claim: uri,
  data: { * tstr => any },
  ? evidence: bstr .size 32,
  ? evidence-uri: uri,
  id: bstr .size 16,
}
agent-id = bstr .size 32
uri = tstr

Lifetime

30 to 180 days by default, 400 days at most.

Attestations are short-lived. Issuers should keep them to 180 days with automatic re-issuance; the 180 day default is enforced by issuing tools only. A verifier rejects any attestation whose expires-at minus issued-at exceeds 400 days (attestation_lifetime_exceeded); exactly 400 days is allowed. An attestation of any type that carries evidence counts as audit-backed.
