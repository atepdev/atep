Claim types

https://atep.dev/claims/

An ATEP attestation names what it asserts with a claim type, a URI. ATEP reserves https://atep.dev/claims/ for a closed core set of 14 claim types, listed here: seven core claim types and the seven of the robotics profile (ATEP-R). Each URI resolves to a definition, who issues it, the CDDL schema of data, and the evidence and lifetime rules. Anyone may use their own namespace for other claim types.

Fetch a claim URI with a browser for the page, with Accept: application/json for the JSON document, or add .json or .html to the path. The directory itself is also available as /claims/index.json. Robotics claim types live under /claims/robotics/. Sections 7 and 17 of the specification define the vocabulary.

Core claims

ClaimStatusDefinitionIssued by

operatorcoreSubject is operated by the named legal entity.Any issuer (in ATEP-R, the fleet operator)
successorcoreSubject replaces the issuer's identity (key rotation).The subject's old identity
retiredcoreSubject is permanently retired. Self-issued.The subject itself
issuer-authoritycoreSubject may issue the listed claim types (chain delegation).A root issuer or a delegate
auditedcoreSubject passed the named audit on the given date; evidence hash required.Auditor
registry-endpointcoreSubject operates the service at the given URL (registry, verifier, MCP server or A2A agent).The endpoint operator (usually the subject itself, or its domain owner)
