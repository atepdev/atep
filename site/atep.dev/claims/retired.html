Claims / retired

Retired

https://atep.dev/claims/retired core

Subject is permanently retired. Self-issued.

Definition

Self-issued: subject and issuer MUST be the same identity. It takes effect at its own issued-at. Afterwards any other envelope signed by that identity with an issued-at at or after the retirement MUST be rejected (step 8). No issuer can block or lift it (spec section 16 point 7).

The data layout

CDDL (RFC 8610) schema of the data map of an attestation with this claim:

retired-data = { ? reason: tstr, * tstr => any }   ; subject MUST equal issuer

Example data in JSON form:

{
  "reason": "decommissioned"
}

The whole attestation payload around data:

attestation = {
  subject: agent-id,
  issuer: agent-id,                      ; MUST equal the envelope signer
  claim: uri,
  data: { * tstr => any },
  ? evidence: bstr .size 32,
  ? evidence-uri: uri,
  id: bstr .size 16,
}
agent-id = bstr .size 32
uri = tstr

Lifetime

30 to 180 days by default, 400 days at most; expiry is not compared when it is consulted at step 8.

Attestations are short-lived. Issuers should keep them to 180 days with automatic re-issuance; the 180 day default is enforced by issuing tools only. A verifier rejects any attestation whose expires-at minus issued-at exceeds 400 days (attestation_lifetime_exceeded); exactly 400 days is allowed. An attestation of any type that carries evidence counts as audit-backed.
